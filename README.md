# 谷绊 GUZI BOND｜比赛版 · 第二阶段云端谷仓

本版本已绑定 CloudBase 环境 `guzibond-d0g911rredd57c82d`，新增邮箱账号体系、账号专属云数据库、图片云存储、跨设备同步、退出后的本地隐私隔离，以及旧版真实档案一键迁移。项目固定使用 CloudBase Web SDK 2.28.6，避免比赛现场自动更新造成故障。

## 直接运行

直接双击 `index.html` 时可以预览页面并打开登录弹窗，但真实注册、云数据库和云存储必须通过已配置的 `localhost` 或正式 HTTPS 域名访问。建议使用最新版 Chrome 或 Edge，并在当前目录启动本地服务器：

```bash
python -m http.server 8080
```

随后访问 `http://localhost:8080`。

## 首次部署前必须完成的 CloudBase 配置

1. 进入环境 `guzibond-d0g911rredd57c82d`。
2. 在“身份认证 → 登录方式”中开启邮箱密码登录，并配置验证邮件发件方式。
3. 在“环境配置 → 安全配置 / 安全来源”中加入：
   - 本地测试：`localhost`；
   - 正式测试：`guzibond.netlify.app`；
   - 后续正式域名。
4. 在“数据库 → 文档型数据库”中新建集合：`guzi_archives`。
5. 为 `guzi_archives` 选择“自定义安全规则”，粘贴：

```json
{
  "read": "doc.ownerId == auth.uid",
  "create": "doc.ownerId == auth.uid",
  "update": "doc.ownerId == auth.uid",
  "delete": "doc.ownerId == auth.uid"
}
```

6. 在“云存储 → 权限 / 安全规则”中选择自定义规则，粘贴：

```json
{
  "read": "resource.openid == auth.openid || resource.openid == auth.uid",
  "write": "resource.openid == auth.openid || resource.openid == auth.uid"
}
```

7. 保存设置，等待安全域名生效后，重新部署全部文件。

安全规则不能设置成“所有用户可读写”，否则会造成不同谷主数据串仓。

当前环境配置：

```js
export const cloudbaseConfig = {
  env: 'guzibond-d0g911rredd57c82d',
  region: 'ap-shanghai'
};
```

环境 ID 是允许出现在网页前端的公开配置。不要把 SecretId、SecretKey、管理员密钥或腾讯云账号密码写入任何前端文件。

## 第二阶段验收清单

- 注册：收到验证邮件，未验证账号不能直接作为正式账号使用；
- 登录：刷新页面后仍保持登录；
- 找回密码：能收到重置邮件；
- 退出：账号信息立即从页面移除；
- 新建：登录后创建一件谷子，数据库出现一条记录，云存储出现对应图片；
- 跨端：另一台设备登录同一账号，可以看到同一件谷子；
- 隔离：第二个账号看不到第一个账号的私密谷仓；
- 迁移：旧版自己创建的档案可迁移，三件示例藏品不会迁移；
- 删除：删除档案后，数据库记录与图片一起删除；
- 退出：退出账号后恢复演示数据，不显示上一个账号的缓存。

## 数据规则

- 未登录：仅显示内置演示档案；
- 已登录：云数据库是正式数据源；
- 云端读取失败：保留当前缓存并明确提示，不用空数据覆盖；
- 每个账号使用独立的本地缓存键，避免同一浏览器切换账号时泄露上一个账号的数据；
- 图片上传到 `users/{uid}/guzi/{archiveId}/`，数据库只保存云文件 ID；
- 初次登录且云仓为空时，才询问是否迁移旧档案。

## 重要说明

当前是可交互的高保真前端正式演示版，数据保存在本机浏览器中。

“智能扫描”按钮用于演示识别后的产品流程，并非真正的 AI 图像识别。正式上线需要接入：

- 用户登录与云端数据库
- 对象存储与图片审核
- AI 抠图、IP/角色识别、OCR
- 真实二维码与唯一身份链接
- 分享落地页与好友互动
- 交易/转赠合规机制
- 内容安全、隐私与版权授权机制

## 推荐正式技术栈

- 前端：Next.js / React / TypeScript
- UI：Tailwind CSS + Framer Motion
- 后端：NestJS 或 Spring Boot
- 数据库：PostgreSQL + Redis
- 图片：对象存储 + CDN
- AI：视觉大模型 + 抠图模型 + 自建 IP 商品库
- 动态谷子：WebGL / Live2D / Spine / 分层动效
- 部署：Vercel / 阿里云 / 腾讯云
